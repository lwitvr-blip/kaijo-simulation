# 海の法規アドベンチャー

日本の海を自分で操船しながら、**海上衝突予防法・海上交通安全法・港則法**の考え方を遊びながら身につける、ブラウザゲームです。
インストール不要で、パソコンでもスマートフォンでも遊べます。

**▶ 遊ぶ：** `https://【ユーザー名】.github.io/【リポジトリ名】/`（公開後に書き換えてください）

> ⚠️ **学習・娯楽用です。実際の航海・操船・試験の根拠には使わないでください。**
> 地図・港・灯台・航路の位置は概略で、法令の記述も学習用の要約です。正確な内容は、必ず法令の原文や海図等でご確認ください。

## 遊び方

| 操作 | 内容 |
|---|---|
| 針路 | 下の羅針儀をタップ／ドラッグ。◀1°／1°▶で微調整。キーボードは ← →（Shiftで10°）、スペースで針路固定 |
| 機関 | 右のレバーを上下にドラッグ（上＝前進、下＝後進）。「停止」ボタンですぐ停止。キーボードは ↑ ↓、X で停止 |
| 画面の拡大縮小 | 画面の ＋／－、ピンチ操作、または「自動」ズーム |
| 右上の地図 | タップで縮尺が5段階に切り替わります |
| 寄港 | 港の約1海里以内で、6ノット以下に減速すると寄港できます |

最初にチュートリアルが表示されます（設定画面からもう一度見られます）。

## 特徴

- 日本全国の実際の海岸線を使った2Dの海図の上で、衝突・座礁に注意しながら自分で操船します。
- 出発する港を選べます（関門・横浜・東京・名古屋・神戸・大阪 ほか）。
- 特定港に寄港して**特産品**を集め、地域をコンプリートすると新しい船が手に入ります。
- 乗客を乗せて目的の港へ届ける依頼で**マイル**を稼げます。
- 他の船は、海上交通安全法の航路・フェリー航路などをもとにした航路網に沿って航行します（実際のAISデータではありません）。
- 他の船と近づくと**「避航」「保持」「右へ」**などの札が出て、すれ違ったあとに採点されます（第13〜18条の考え方）。
- 海上交通安全法の11航路を、幅つきの帯で表示します。
- 島・岬・灯台・一般港・海峡名などを小さく表示し、遊びながら地名を覚えられます。
- 衝突・座礁したときは、該当する法令の考え方の解説が表示されます。

## 既知の制限（正直なところ）

- **航路・港・灯台・島の位置は概算です。** 海上交通安全法は航路の区域を文章（地名）で定めており、座標は海図上の線です。本ゲームでは、法令に出てくる灯台の座標、公表されている各航路の長さ・幅、海岸線データをもとに作成しており、**1〜2海里程度ずれている可能性があります。**
- 他船の動きは、航路網から作った**モデル**です。実際の船の動きではなく、漁船は海岸近くに出る簡易的な表現です。
- 他船の船名は、ゲーム用に作った一般的な名前です。実在の船とは関係ありません（偶然の一致があっても関係ありません）。
- 「避航／保持」の判定・採点基準は学習用に簡略化したものです。実際の航法の判断は、状況や他の船の動きに応じて変わります。
- 特産品・特別アイテム・価格・マイルの経済は、ゲーム用の創作です。
- 港則法の特定港の一覧は、公式のものと完全には一致しない可能性があります。
